🎯 What is Negative Knowledge?

Negative Knowledge represents the unknown unknowns in scientific research — connections that should exist but haven't been studied yet. While traditional literature reviews tell us what has been studied, Negative Knowledge reveals what has been missed.

The Problem: Over 2.5 million research papers are published every year. No researcher can read all of them. This means promising connections between concepts studied in different sub-fields go unnoticed for years or decades.

Our Solution: Using Graph Neural Networks (GNNs) combined with deep biomedical language models (SciBERT), we construct knowledge graphs from research papers and predict which connections are missing. The system explains every prediction through gradient-based GNN attribution.

🔬 NLP Entity Extraction

Stage 1
Biomedical NER

Two scispaCy models run in parallel: en_core_sci_sm (broad scientific terms) and en_ner_bc5cdr_md (diseases & chemicals). Maximizes both recall and precision.

Stage 2
Synonym Normalization

Hand-crafted synonym map unifies entities (e.g., "major depressive disorder" → "depression", "cbt" → "cognitive behavioral therapy").

Stage 3
Entity Classification

5 categories via keyword rules: Disorder, Therapy, Risk Factor, Outcome, Population. Non-medical terms are discarded.

Stage 4
Relation Extraction

Sentence-level co-occurrence with optional negation detection (NegEx). Creates pairwise "related_to" edges between entity pairs within same sentence.

🧠 Hybrid 896-Dimensional Feature Vector

Core Innovation: Every node is represented by a two-part 896D vector encoding both graph structure AND medical semantics.

Node2Vec — 128D (Topology)

  • Biased random walks (p=1.0, q=0.5)
  • 200 walks × 20 steps per node
  • Word2Vec Skip-gram → 64D vectors
  • Zero-padded to 128D
  • Captures graph neighborhood structure

SciBERT — 768D (Semantics)

  • Pre-trained on 1.14M scientific papers
  • 12 Transformer layers, 110M parameters
  • Custom 31,116-token scientific vocabulary
  • [CLS] token extraction for sentence embedding
  • Medical meaning even for isolated nodes

Concatenation (not averaging) preserves both signals: [128D Node2Vec | 768D SciBERT] = 896D. The downstream GCN learns to weigh them differently per prediction.

🧬 GNN Architecture

GCN Encoder

INPUT: X ∈ ℝ^(659 × 896) — Raw 896-D hybrid features Step 0: BatchNorm1d(896) — Normalize input features Step 1: Linear(896 → 128) + ReLU — Dimensionality reduction Step 2: GCNConv(128 → 128) — 1st graph convolution BatchNorm + ReLU + Dropout(0.45) Step 3: GCNConv(128 → 64) — 2nd graph convolution BatchNorm OUTPUT: Z ∈ ℝ^(659 × 64) — Learned node embeddings

Hybrid Decoder

Branch 1 — Bilinear: score = zᵤᵀ · W · zᵥ + b (W ∈ ℝ^64×64) Branch 2 — MLP: [zᵤ | zᵥ | zᵤ⊙zᵥ] → 192→32→1 Final: P(link) = Sigmoid(score_bilinear + score_mlp)

🔬 Explainable AI — Gradient-Based GNN Attribution

Every prediction is fully explainable using gradient-based attribution — the GNN equivalent of Grad-CAM. This is model-intrinsic (not approximate), computed in <200ms, and decomposes into topology vs. semantics contributions.

Step 1: Enable gradients on 896D input features Step 2: Forward pass through GCN Encoder → 64D embeddings Step 3: Compute link score via HybridDecoder Step 4: Backpropagate gradients to input features Step 5: importance[d] = |gradient[d]| × |feature[d]| Step 6: Split — dims 0-127 = topology, dims 128-895 = semantics
